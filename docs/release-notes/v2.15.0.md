## What's changed

**Self-update installs reliably.** Clicking "update" could download the new version, close the app, and then bring back the old version instead of the new one. The installer swaps the whole app folder, and when Windows briefly held that folder right after the app closed (usually antivirus scanning the freshly extracted files), the installer relaunched the app, the relaunched app immediately re-ran the installer, and the overlapping runs kept the folder locked until the update gave up. Three things changed: only one installer run can touch the app folder at a time and any extra run steps aside immediately; a relaunch after a failed swap no longer re-runs the installer, leaving the update to install cleanly on the next start; and a single attempt now waits out short-lived locks instead of giving up early.

**Nothing else changed.** This release only makes installing future updates dependable; day-to-day behavior is identical to 2.14.0.

Note: this update itself is still installed by the previous version's flow. If it does not land on the first try, simply close and reopen the app once; from this version onward the full protection applies.
