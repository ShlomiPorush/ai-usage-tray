## What's changed

The remote viewer now shows its deployed server version as a compact badge beside the AI usage title. This makes it easier to confirm which web build is active without using space at the bottom of the page.

Desktop test notifications no longer open the usage tooltip when the pointer is elsewhere. Normal pointer hover over the tray icon continues to open the tooltip as expected.

The updated remote viewer is included in container image `1.1.1`. Publishing the image does not deploy it to an existing server; the server owner must update the running container separately.
