## What's changed

**See one model on its own.** In the Usage window, click a model in the breakdown table to open a panel for that model alone. It shows:

- The model's API value, its tokens, its cost per million tokens, and how much of its input came from the prompt cache.
- A chart of that model's usage for the range on screen, in API value or tokens. While two periods are compared, it adds the model's period B as a dashed line, period B's figures under the totals, and the same notes about the comparison as the top of the window.
- Two bars that split the model's API value and its tokens by type: input, cache read, cache write and output.

Close the panel with the X, the Escape key, or a click outside it. Clicking a day still opens that day by hour.

**Read exact figures on the charts.** Point at either chart to see a guide line and the exact figures for that day or hour: each provider, their total, and period B with its own date while comparing.

## Known limitations

- A model with no known price shows its tokens only, since its value cannot be split by type.
- At the smallest window size, the panel scrolls.
