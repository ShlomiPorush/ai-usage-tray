## What's changed

**Updates install even when the app folder is held open.** The installer used to swap versions by renaming the whole app folder, and Windows refuses to rename a folder that anything is holding on to. Having the install folder open in an Explorer window was enough to make every update fail with "the item is in use", update after update, until the window was closed. The installer now notices the failed rename and instead replaces the files inside the folder one by one, with a safety copy of the old files and a full rollback if anything goes wrong. An open Explorer window, or any other program holding the folder, no longer blocks updates.

**Nothing else changed.** Day-to-day behavior is identical to 2.15.0.
