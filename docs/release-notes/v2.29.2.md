## What's changed

**Claude usage is no longer counted twice in the Usage history.** The Usage dashboard could count Claude usage twice when the same log files came to count under another account: after an account's folder was changed in Settings, after a session was moved to another account's folder, or after accounts that share one `projects` folder were removed or reordered. The usage history now saves Claude requests one by one, by the ids that Claude Code writes in its logs, so a request is counted once wherever its log file goes.

- The first history sync of this version marks the Claude requests already in the logs where they were counted. It does not change stored totals.
- **Delete history** now finishes a delete that was interrupted the next time the app starts. Until that finishes, the app saves no history, and Settings shows this.

**Limits.** This version does not remove duplicates that are already in a saved history. If you run an older version of the app after this one, it can count Claude usage twice again.
