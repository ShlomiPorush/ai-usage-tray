## What's changed

**A new dark style.** The dark theme now uses neutral charcoal greys instead of navy blue. The usage colours (green, yellow, orange and red) stand out more clearly against it, and the widget, Settings and the Usage dashboard all follow it.

- **Blue steel is still there:** if you prefer the previous dark look, choose **Blue steel** in **Settings > Display > Dark style**. The choice applies whenever the app is dark, and it is included when you export and import settings.
- **Clearer reset expiry notice:** in the charcoal style, the "reset expires within 7 days" notice on an account now has an amber background and an amber edge, so a reset that is about to expire is easy to spot. The light theme and Blue steel show it as before.

## Known limitations

- **The new look is the default:** everyone who sees the dark theme gets the charcoal style after updating, both with **Dark** and with **Follow system** while Windows is dark. To go back to the previous look, choose **Blue steel** under **Dark style**.
- **Web viewer unchanged:** the remote web view keeps its own dark look.
