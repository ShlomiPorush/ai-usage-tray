## What's changed

Disconnected Claude and Codex accounts now offer a Relogin action in both the widget and Settings. The app launches the provider's official CLI with the correct account profile, then reloads the account and refreshes its usage after sign-in completes.

Browser alerts now reflect the device's real subscription state. The remote viewer switches between Enable alerts and Disable alerts, gives the active state a distinct green treatment, and explains blocked or unavailable browser push instead of showing a generic failure.

The primary remote-view server now creates and safely persists its browser notification keys automatically. The viewer also shows its deployed remote-view version in the footer, making it easier to confirm which web build is running.
