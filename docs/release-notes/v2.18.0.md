## What's changed

**See the past 24 hours hour by hour.** The usage window has a new **Past 24h** range next to 7, 30 and 90 days. It covers exactly the last 24 hours and splits them into hours, so you can see when during the day your usage happened, not just that a day was expensive. The chart shows every hour, and the breakdown's **Hour** view lists the hours that had activity, newest first. Hours stay correct across a daylight-saving change.

**Codex usage is no longer counted twice.** When Codex starts a subagent, the subagent's log begins with a copy of what the parent thread had already done. The usage window counted that copy again, which overstated Codex usage and cost by about a fifth. Some of the copied usage also showed up as an unpriced "unknown" model. Copied history is now skipped, so Codex figures will be lower after this update. The lower figures are the correct ones. The subagent's own work is still counted in full.
