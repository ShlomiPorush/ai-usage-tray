## What's changed

**Deleting usage history no longer pauses saving.** In the previous version, a **Delete history** that could not finish, for example because another program held a history file, stopped the app from saving usage history for every provider until it finished. Now the deleted usage is hidden at once and saving goes on. If some files could not be removed, Settings asks you to try again, and the next **Delete history** removes them.

- **Simpler history files:** the history now keeps one small record of the last delete, and the code around it is much smaller. Saved usage is kept, and each Claude request is still counted once.
- **Model prices:** adds prices for Claude Fable 5.2, Claude Mythos 5.2, GPT-6.2 Astra, GPT-6.2 Astra Law, GPT-6.2 Sol and GPT-6 Cyber, and lowers the price of GPT-6 Rosalind to its current one. The app already downloads new prices every day. These are the ones it uses when it has no downloaded prices.

## Known limitations

- **A delete that had not finished before the update:** this version does not continue it, so the usage it removed may show again. Run **Delete history** once more.
- **A damaged history state file:** if a disk fault damages `state.json` in the history folder, the app forgets when history was last deleted, and deleted usage whose logs or files are still on disk can show again.
- **Older versions:** running an older version of the app after this one can still count Claude usage twice.
