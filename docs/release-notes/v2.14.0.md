## What's changed

**Claude usage-limit resets, visible and usable.** Claude subscriptions now come with redeemable usage-limit resets (what `/limit-reset` does in Claude Code). The app now shows them on your Claude accounts the same way it already does for Codex: a quiet chip on the account card, an expiry date, and a select, review and confirm flow to use one from the desktop app. A promotional reset can clear the session limit, the weekly limit and the model-scoped weekly limit at once, and the confirmation spells out what the selected reset covers.

**No accidental double spend.** Using a reset is always an explicit action; background monitoring never redeems one. If the network drops mid-redemption and the answer is uncertain, retrying is safe: the app replays the same request instead of minting a second redemption, and this protection survives an app restart.

**Resets on the web viewer too.** The remote view shows Claude resets with their expiry, including grants that carry more than one use. Redemption stays desktop-only.

Self-hosters: relay image 1.3.0 pairs with this release (viewer support for Claude resets and multi-use grants). See the remote/server README for the pinned tag.

Note: Anthropic serves the reset data only to clients it considers recent enough. If Claude resets ever disappear from the app while `/limit-reset` still shows them in Claude Code, update the app; a future release will carry the newer client version.
