## What's changed

**An empty Usage window tells you why.** Before, an empty Usage window said only "No local agent usage in this range." The window reads only the logs that Claude Code and Codex write on this computer, so usage on claude.ai, ChatGPT or the desktop chat apps never appears there. The message now names the cause:

- No Claude Code or Codex logs were found in your accounts' folders.
- The logs hold no usage yet, for all accounts or for the account you picked.
- Usage exists, but not in the days on screen. The message shows the days that hold usage, for example "Recorded usage: Aug 6 to Oct 27", and says when older logs may have been deleted.

**You can see when a comparison is on.** While two periods are compared, the **Compare** button reads **Comparing** in the accent colour, and screen readers announce the same. Picking another range changes period A only, so the comparison stays on until you turn it off.

**Clear filters.** A **Clear filters** link appears above the dates when you picked an account, a range other than 30 days, or a comparison. It returns the window to all accounts and the last 30 days, without a comparison. Your sort order and the model or day view stay as they are.

**Prices.** The bundled price list adds `gpt-6.1-terra`.
