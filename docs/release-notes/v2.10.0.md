## What's changed

This release makes reset notifications match the weekly quota cycle. A five-hour Session window reaching 0% no longer triggers a reset notice, while genuine Weekly resets continue to notify on Windows and through the remote viewer.

You can now send a test notification from the desktop Alerts settings or the browser viewer. The test stays local to that device, so it does not upload fake usage or alter the remote subscription.

The browser shell and rollback Worker were updated together, so both remote delivery paths use the same weekly-only reset behavior.
