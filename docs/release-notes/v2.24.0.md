## What's changed

**Usage report on the remote view.** The remote view used to show only quota percentages, so your cost and token report was visible only on the PC. In Settings > Remote view there is now a "Share usage on the remote view" option, off by default. When it is on, the remote view gets a Usage tab with the same report as the desktop Usage window: Past 24 hours, 7, 30 and 90 days or custom dates, comparisons, the account filter, Cost or Tokens, the chart, the tiles, the breakdown by model or day, and model details.

- What is shared: account nicknames, model ids, token and request counts, and the estimated API value, per day and per hour. Prompts, file paths, project names, credentials and internal account ids are never sent. An account without a nickname appears as "Claude account 1", "Claude account 2" and so on.
- The report is updated at most every 10 minutes, and only when something changed.
- Turning the option off removes the shared report from the relay. If the relay cannot be reached, the app keeps retrying; otherwise the report expires within a week.

## Known limitations

- The Usage tab needs the remote view relay version 1.6.0 or later. On the Cloudflare Worker relay the tab does not appear.
- Hourly detail is shared for the last 7 days. Older days are shown by day, and a period outside the shared data is marked "Partial data".
- The Past 24 hours view shows the window as of the last report the app uploaded.
