## What's changed

**Your usage appears right away after a restart.** Before, the tray and the widget stayed empty after a restart or an update until the first refresh finished. Antigravity stayed empty for up to the check interval you chose, and the remote view showed it as an empty card. Now the tray shows each account's last known usage immediately, with the time it was read, while the first refresh runs.

- **What is stored:** usage percentages, reset times and the plan name. Names, emails, folder paths and sign-in details are not stored.
- **Stored usage is display only:** it never triggers an alert, is never sent to the remote view and never starts a session window.
- **When it is left out:** a window that has reset since it was read, and a window without a reset time after one day.
- **When it is cleared:** whenever you add, edit or remove an account, import settings or sign in again.
- **Antigravity:** keeps the result of its last successful check, so after a restart it shows that result until the next check is due. After a failed check it shows the failure, not an older result.

**Claude accounts stay connected when no session window is open.** While no five-hour window was open, Claude accounts could show "Claude subscription is not connected" even though the sign-in was valid. They now show their weekly limits, and the Session row appears again once a window opens. Rows without data also show the right provider icon and the Relogin button.

**Tidier remote view.** Account cards on the remote view now fill columns from the top, so a short card no longer leaves an empty gap under it. A single card is centred.

## Known limitations

- **Relay version:** the gap-free card layout needs relay version 1.7.1 or later.
- **Sign-in in progress:** while a sign-in window is open from Settings, the app does not store usage.
