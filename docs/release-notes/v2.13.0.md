## What's changed

This release hardens the app and the remote view after a full security review. Everything below was verified with automated tests; day-to-day behavior stays the same unless noted.

**Accounts stay separate.** Claude accounts whose profile folders share the same folder name (they usually all end in `.claude`) could read each other's cached usage and identity inside the app. Each account now has its own cache, keyed by the full folder path.

**Safer helper launches.** The app now starts PowerShell, cmd and the claude/codex command-line tools from their full, trusted locations instead of searching by name, so a program planted in a writable folder can no longer run in their place.

**Session activation is bounded.** A provider that keeps reporting an old reset time could previously trick the app into starting paid sessions repeatedly. After a successful activation the app now waits out the full five-hour window before activating again, no matter what the provider reports.

**Reset credits are not redeemed twice.** The confirmation key for using a Codex reset now survives an app restart, so retrying after a crash or restart cannot redeem the same credit again.

**Custom relay addresses fail safe.** If you point remote view at your own server and the address is invalid (for example it starts with http instead of https), the app now stops uploading entirely and says so in Settings, instead of quietly sending your data to the built-in relay. The built-in relay is used only when no custom address is set.

**Uploads are signed.** Snapshots sent to the relay now carry a signature, which relay 1.2.0 and newer uses to tell real apps from abusive scripts and rate-limit accordingly. This works with older relays too, and older app versions keep working against the new relay.

**Single instance without silent exits.** If something else holds the app's single-instance lock without being a real running instance, the app now starts anyway instead of exiting silently with no tray icon. The window that tells another instance to show itself is restricted to your own user account.

Self-hosters: relay image 1.2.0 pairs with this release (upload signing, per-address rate limits, non-root container, honest health checks). See the remote/server README for the new environment variables.
