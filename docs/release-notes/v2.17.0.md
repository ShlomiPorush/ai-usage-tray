## What's changed

**New models are priced without waiting for an app update.** The usage dashboard used to price tokens from a list built into the app, so any model released after that build showed as "unpriced" until the next release. The app now downloads the public LiteLLM price list once a day, the same list most AI cost dashboards use, so new models get a price almost as soon as they are published. A copy of the list ships with the app for times it cannot go online. The download is a plain request for a public file: nothing about you or your usage is sent.

**Corrected prices.** Claude Sonnet 5 is now priced at $2 / $10 per million tokens (it was $3 / $15), and o3 at $2 / $8 (it was $10 / $40). Claude Opus 5.5, Claude Fable 5.1 and GPT-6 Astra are now priced instead of being listed as unpriced.

**Your own prices still win.** `%LOCALAPPDATA%\costats\pricing.json` overrides any listed price and can price models no list covers. Edits to it now show up on the next report, without restarting the app.

**Known limitation.** Some Codex tokens are still listed under "unknown" because the log does not say which model produced them yet. This is tracked separately.
