## What's changed

You can now review all available Codex usage resets inside the existing widget. Each reset shows its description, grant date, expiry date and days remaining. Choose a specific reset and confirm before using it, then return to the same account without opening another window.

An information notice in the widget and web viewer highlights resets that expire within 7 calendar days. Click the reset chip in the web viewer to open the full list of reset details.

The app checks the selected reset again before using it and blocks redemption when the provider returns an incomplete list. Reset use requires Codex 0.154.0 or newer and always needs your explicit confirmation. Background monitoring never uses resets automatically.

The web popup requires remote viewer image 1.1.4 or newer and a fresh snapshot from the updated desktop app. The web viewer displays reset details; resets are used from the desktop app.
