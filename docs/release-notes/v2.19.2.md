## What's changed

**Relogin signs you in to Codex again.** When a Codex account needed a new sign-in, the **Relogin** button only flashed a PowerShell window that closed at once. With Codex installed through npm, Windows PowerShell picked a script file that its default security settings block. Relogin now starts the Codex program itself, so the sign-in opens normally, and the same applies to the first-run setup window.

**The sign-in window closes by itself.** After a successful sign-in the window closes and the account's usage refreshes right away. If the sign-in cannot finish, the window stays open, says why, and waits for Enter so you can read it. For Claude accounts, type `/exit` in Claude Code when you are done.
