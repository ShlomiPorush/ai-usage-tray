## What's changed

**Antigravity in the Usage dashboard.** The Usage dashboard counted only Claude Code and Codex. While Antigravity is enabled, it now also counts the tokens Antigravity used and prices them at the published Gemini API rates, next to Claude Code and Codex in the totals, the chart and the model table.

- **Where it reads:** the conversation files of the `agy` CLI and of every profile T3 Code runs Antigravity under. All of them appear as one account, **Antigravity (all sources)**, because a conversation file does not say which Google account ran it.
- **What it reads:** only the model, the time and the token counts of each model call. The prompt text in the same files is never read, stored or logged.
- **History:** Antigravity usage is kept in the usage history like the other providers, so it stays after Antigravity deletes a conversation. Deleting the history and the retention setting apply to it too.
- **Shared usage:** the shared usage report on the remote view includes Antigravity once the relay runs version 1.9.0 or later.

**Reorder accounts on the remote view.** Each account card on the remote view has a grip handle: drag it with the mouse or a finger, or move it with the keyboard. The order is kept per browser and per shared view, new accounts appear at the end, and **Reset order** brings back the default order with the primary account first.

## Known limitations

- **Antigravity file format:** Antigravity does not document its conversation format. The app reads it based on real files and skips any record that does not fit, so an Antigravity update can make some usage stop being counted until the app is updated.
- **Antigravity desktop app:** conversations of the Antigravity desktop app are kept in another format and are not counted.
- **Older versions:** installing an older version of AI Usage Tray removes Antigravity usage from the months of history it saves.
- **Relay version:** Antigravity in the shared usage report needs relay version 1.9.0 or later. An older relay gets the report without it.
