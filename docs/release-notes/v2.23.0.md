## What's changed

**Usage history that outlasts the logs.** Claude Code deletes its transcripts after 30 days, so the Usage window used to forget older usage. AI Usage Tray now saves the token counts it reads, so the 90-day view and custom ranges keep showing older usage after the logs are gone.

- Saving runs in the background, a minute after the app starts and then every 6 hours. Only token counts, request counts, model names and account nicknames are saved, in `%LOCALAPPDATA%\AIUsageTray\history`. No message content is saved.
- On the first run, usage that is still in the app's cache from logs Claude Code already deleted is recovered. It appears as "Earlier Claude history (account unknown)", because the cache does not record which account those logs belonged to.
- An account you remove keeps its history, shown as "(removed)".
- In Settings > Local usage data, choose how long to keep the history (1 year, 2 years, or forever; 2 years by default), or delete it. Deleting hides all usage before that moment, even if its logs are still on disk.

**Tokens across the whole Usage window.** Switching the chart to Tokens now also switches the headline total and the Claude Code and Codex rows to tokens. The estimated API value stays visible under the total.

## Known limitations

- History starts from what was still on disk or in the cache when you first run this version. Usage from logs that were already deleted and never read by the app cannot be recovered.
- In rare cases, a request that Claude Code copies into a resumed session under another account can be counted on both accounts.
